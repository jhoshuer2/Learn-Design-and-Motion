## Learner's rationale

First, the event name is set in the largest, darkest block so it is read before anything else. Second, the date and venue sit in a mid-dark tone below it, clearly secondary but still high contrast against the cream ground. Third, the call to action is the only saturated blue on the page, so the eye lands on it last and knows what to do.
