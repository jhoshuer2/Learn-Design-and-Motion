## {objective} Where we are going
By the end you can:

- explain what the seam of a loop is;
- match the end of your animation to its start;
- hide the join with an overlap.

## {concept} The idea in one minute
<<video:make-it-loop|A loop of frames, a jump at the seam compared with a smooth one, copying the first keyframe to the end, and an overlap that hides the handover. Captions explain each.>>

A loop replays forever, so the **last frame must lead back to the first**. The join is the **seam**. The simplest fix: copy your first keyframe values to the very end. For text, let one word start leaving while the next arrives, so the join is hidden.

## {realWorld} Where you have seen this
Loading spinners, background animations and GIF stickers all loop. The best ones you never notice restarting.

## {goodVsBad} Spot the difference
- **Jumps:** ends far from where it started.
- **Seamless:** ends exactly where it started, with matching speed.

Even a tiny difference shows when it repeats 50 times.

## {guided} Try it with me
1. Open your word animation from last time.
2. Make the very last frame show the same state as the first (copy the first keyframes to the end).
3. Set the loop or repeat option in the tool and watch it five times.
4. Look only at the restart. Do you see a pop? If yes, nudge the end values or add a short overlap.
