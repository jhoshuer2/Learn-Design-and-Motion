## {objective} What you will be able to do
By the end of this lesson you can:

- divide a page into columns, margins and gutters;
- align text and shapes to the same edges so the page looks ordered;
- set repeated items (such as a list of sessions) in parallel;
- use one spacing scale so that gaps mean something.

## {concept} A grid is an invisible set of rules for placement
A **grid** divides a page into regular parts so that things line up. The parts are:

- **Margins**: the empty border around the content;
- **Columns**: vertical bands that hold content (a simple page may use one, two or three);
- **Gutters**: the gaps between columns;
- optionally **rows** or a **baseline** for vertical rhythm.

Every element **snaps** to the grid: its left edge starts on a column line, its width spans whole columns. The result is **alignment**: many items share the same edges, and the eye reads that as order.

Three ideas make a grid work:

- **Alignment.** Prefer a few strong edges (one left edge for text, say) over many near-misses. A gap of a few pixels between edges looks like a mistake.
- **Parallel structure.** Items of the same kind (three sessions, four prices) are set **the same way**: same order, same sizes, same spacing.
- **A spacing scale.** Choose a few gap sizes (for example 8, 16, 32 and 64 units) and reuse them, so closeness tells the viewer what belongs together.

Two rules to carry through this module:

1. If two edges are close but not the same, make them the same.
2. Repeat anything that repeats: same structure, same spacing.

## {realWorld} Where you meet this every day
Look at a timetable or a price list. Every row has the same structure and starts on the same edge. Newspapers and magazines place columns on a grid so you can follow stories from page to page.

Now think of a flyer where each block was placed wherever it fitted. You can read it, but it feels untidy and you cannot tell which items belong together.

## {guided} Try it with support
Take a page with a list, a schedule or a price table. Work through these steps:

1. Draw vertical lines through the left edges you can see. How many different edges are there?
2. Find items that repeat and check whether they are set identically.
3. Measure three gaps. Do they come from a small set of sizes?
4. Pick one near-miss edge and describe how you would snap it to the grid.

Keep your notes. You will use them in the independent task.
