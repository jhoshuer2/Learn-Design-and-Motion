# What each reference contributed
- Cinematic one-subject heroes (fitness, travel, architecture): one image per screen; type small or huge, nothing in between.
- Editorial cream sites (Halden Mono, Concrete Gardens, Casa Pietra, "Every wave carries a story home"): cream ground, serif with italic phrase, hairline grids, small pill CTA.
- Floating pill dock portfolio: bottom-centre navigation and a tiny left index.
- Micro-interaction showpieces (receipt slider, day/night toggle, expanding pill menu): themed controls with physical feel.
- Library UIs (Unsection style): pill filters with counts, soft card grids, hover actions.
- Gallery wall with "02 / 10": counters and path browsing.
- Character-led heroes and the illustrated companion ad: one warm recurring character.
Everything is re-drawn originally; no reference artwork, text or brand is reused.
